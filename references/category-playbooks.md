# 类目攻略：匹配规则 · 风险阈值 · 购买建议强度

> 参考 Taobao Price Compare（SkillHub AI 评分 4.5）的「类目风险阈值 + 四档购买建议」设计。
> 核心原则：**不要在"规格更低 / 渠道更差 / 券不可得"的原因下推荐更便宜的平台**。

## 一、购买建议四档（报告结论统一用这套）

| 档位 | 判定条件 | 输出措辞 |
|---|---|---|
| 强推荐 | 匹配分 ≥80 + 价格优势 ≥ 该类目阈值 + 渠道可信（自营/旗舰/高评价） | "强推荐：在 XX 购买，比 XX 便宜 YY%（口径一致）" |
| 弱推荐 | 匹配良好但有限制：券后价/会员价才便宜、店铺差异、运费未知、匹配分 60-79 | "弱推荐：XX 更便宜，但需领券/为第三方店铺，注意口径" |
| 仅供参考 | 证据不完整、匹配分 <60、页面被屏蔽、只有近似款 | "仅供参考：XX 有近似款报价，规格不一致，请核对" |
| 无法判断 | 无可比 listing、缺关键口径（规格/日期/位置）、平台未采到 | "无法判断：本次证据不足，建议人工核对" |

## 二、各类目风险阈值（省多少才值得换平台）

> 阈值是经验基线，用于报告结论措辞；不满足阈值时用"弱推荐"甚至不推荐换平台。

### 电商 / 食品饮料
- **手机 / 3C 数码**：省 5-8% 不算优势（保修、渠道、发票、正品风险权重高）；自营/官方渠道优先，第三方低价需查评价与售后政策。
- **家电 / 大件**：省 ≥10% 或含安装/运费差异才值得换；注意发票（报销）、延保、以旧换新。
- **纸巾 / 日用品 / 低风险标品**：省 10-20% 才有意义；比每单位价（元/抽、元/100g）。
- **食品饮料**：必须同品牌同规格同口味；**保质期**必须可比（临期 vs 正期差价正常，要标注）；比每单位价（元/升、元/罐）。
  - **规格假象高发区**：搜索标题常写"12/24罐可选""24罐12罐"等双规格，页面显示价实际对应**最低规格**（如 12 罐）。处理：标题含双规格/异常低价的条目必须开卡看"商品规格/SKU"；能确认主规格实价才入主表，否则降级"规格待核"并标注（规则详见 SKILL.md 第 4.5 步）。
- **美妆护肤**：渠道真伪权重极高；旗舰店/官方授权 vs 代购低价差距大时谨慎；版本（国行/免税/海外）必须一致。
- **服装鞋帽**：同款同码才算同款；尺码/颜色缺货时标注；奥莱/折扣店 vs 正价店口径分离。

### 外卖 / 美食
- 只比同商家同菜品同规格（大份/小份分开）。
- 到手价 = 标价 + 配送费 − 满减/券；**满减不满足门槛、会员红包未到账时，按页面可见价计算并备注**。
- 配送范围/预估送达时间差异要备注（"这家便宜但配送慢 20 分钟"）。

### 图书
- 必须同版次（版次不同内容/页码可能不同）、同出版社、同装帧（精装/平装）、同 ISBN。
- 新旧程度（全新/二手/馆藏）分列；孔夫子旧书注意品相描述。

### 电影 / 演出
- 比**同影城 + 同时段 + 同座位区**的价格；IMAX/杜比 vs 普通厅分开。
- 注意会员折扣、开卡优惠、手续费（猫眼/淘票票不同渠道票面价一致但可能有平台券）。
- 演出注意座位分区价差与黄牛风险（只比官方渠道）。

### 药品 / 健康（安全红线）
- 只比**同厂家 + 同批准文号 + 同规格剂型**（如布洛芬缓释胶囊 0.3g*20 粒 vs 0.2g*24 粒不算同款）。
- 处方药不提供购买链接，仅提示"需凭处方在正规渠道购买"；用药咨询请遵医嘱。
- 官方医保比价小程序数据为权威基准；线上药店价格需标注"是否含运费、是否需开药问诊"。

### 租房 / 住房
- 判断贵贱用**市场基准**：同区域/同户型/同面积的中位数与价格带（贝壳、自如均有同小区均价参考）。
- 比价维度：月租 + 押金 + 中介费 + 物业费 + 水电燃结算方式 + 通勤时间（统一权重）。
- 风险标记：价格显著低于同小区均价（疑似假房源/隔断/托管陷阱）、重复房源去重。

### 酒店 / 住宿
- 比**同日 + 同房型 + 同人数**；注意含早/不含早、免费取消/不可取消、会员价/协议价。
- 结算口径：税后总价（平台常分"房价+服务费+税"）；低价房型注意"无窗/无早"等限制条件。

### 出行 / 票务
- 机票比**含税总价 + 退改规则 + 行李额**；中转 vs 直飞分开；注意"低价不含托运行李"。
- 火车票：12306 为基准价，携程/飞猪比的是"抢票服务费/加速包"——只比票价时用 12306，比服务时单独说明。
- 打车：比一口价/快车/特惠/拼车的**预估价**与优惠券后价；注意动态调价时段。

### 家政 / 本地服务
- 比价对象是服务（保洁/维修/搬家/上门），注意**报价单位**（按小时/按平米/按项）与时长。
- 附加费（材料费、楼层费、超时费）必须单独列出；低价不一定划算，看服务时长与口碑。

### 健身 / 教育 / 充值
- 健身卡/课程：比总价 + 有效期 + 退款规则 + 转卡费；注意"年卡折算月价"口径。
- 教育课程：比课时数 + 有效期 + 答疑/作业批改等权益；机构跑路风险提示（预付费谨慎）。
- 话费/流量/会员充值：比到账时效 + 渠道优惠（支付宝/微信 vs 官方）；注意慢充风险（低价慢充可能来自违规渠道）。

## 三、价格口径统一（所有类别通用）

1. **优先使用无条件可见价**：优惠券适用条件不明确时，用标价；券后价需标注"领券后"。
2. **会员价 / 补贴价 / 拼团价 / 银行卡价 与正常价分开列**，报告标注价格类型。
3. **多件打包**：比较单价与总价（如 24 罐整箱 vs 12 罐*2）。
4. **运费 / 起批量**：1688 批发价含税不含运费（标起批量）；外卖含配送费；酒店含税口径注明。
5. **所有价格标注读取时点**："价格截至 2026-09-17 11:30，可能随券/促销/定位变化"。

# HTML 报告模板规范（多模板，类别区分）

> 读 `html/SKILL.md` 生成报告。模板按类别区分、风格统一、色彩与细节有区别。
> 每类模板保持同一套布局语言（头部信息栏 / 比价表 / 结论卡 / 走势图 / 页脚声明），
> 仅主题色、角标符号、表格强调列按类别微调，避免每类从零设计。

## 一、模板清单与主题

| 模板 | 适用类别 | 主色 | 角标 | 强调点 |
|---|---|---|---|---|
| template-ecommerce | 电商 / 食品 / 图书 / 二手 | 京东红 #E4393C 系 + 白 | 比价（¥） | 单位价列、起批量/运费列加粗强调 |
| template-food | 外卖 / 美食 | 美团黄 #FFC300 系 | 到店（🛵→图标，用 SVG） | 到手价 = 标价+配送−满减 计算式展开 |
| template-entertainment | 电影 / 演出 / 健身 / 教育 | 猫眼绿 #00C26F 系 | 场次（🎬→SVG） | 场次/时段/座位区/有效期列 |
| template-health | 药品 / 健康 | 医保蓝 #2A6CB4 系 | 药品（＋→SVG 十字） | 厂家/批准文号/剂型列；边界声明置顶 |
| template-local | 租房 / 酒店 / 出行 / 家政 | 贝壳蓝 #00BEA6 系 | 位置（⌂→SVG） | 市场基准/总价口径/风险标记列 |
| template-generic | 用户指定 / 其他 | 青田墨绿 #1E3A2F | 比价（≈→SVG） | 默认回退模板 |

共用组件（所有模板一致）：
- 头部信息栏：对象名 + 规格/日期/城市 + 查询时点 + 价格口径说明；
- 比价表：`平台 | 对象与规格 | 价格 | 每单位价 | 店铺/商家 | 销量/评价 | 起批量/运费/配送 | 链接 | 备注`（列随类别裁剪）；
- 结论卡：四档购买建议（强推荐/弱推荐/仅供参考/无法判断）+ 一句依据；
- 走势图：ECharts 折线（历史最低横线 + 当前价标注），数据来自 `price_history.py export`；
- 价格带定位：当前价处于近 90 天分布的分位（便宜/正常/偏贵）——数据 ≥2 条才显示；
- 页脚：数据来源平台清单 + "价格截至 <时点>" + 边界声明（按类别）。

### 价格带定位的视觉标注（统一规范）

- 在走势图下方或当前价标签旁，用一个三段色带标注当前价所处位置：**便宜（绿，<25% 分位）/ 正常（灰，25%~75%）/ 偏贵（橙，>75%）**；
- 标注形式：一条 0~100% 的横轴，画一个指示标指向当前价分位，并配文字"当前处于近 90 天 X% 分位（便宜/正常/偏贵）"；
- 同时在走势折线图上标注"历史最低"横线与"当前价"竖线，让用户一眼看到当前价相对历史的位置；
- 历史样本 <2 条时，该区域显示"基线已建立，持续采集后出价格带"，不画指示标、不给分位结论。

## 二、生成步骤

1. 读 `html/SKILL.md`（设计规范与自检流程以它为准）。
2. 按类别选模板主题（上表）。
3. 组装数据：
   - 比价表行：采集结果（已过 `normalize.py dedupe` 聚合 + `confidence` 评分）；
   - 走势图：`python scripts/price_history.py export data/price_history.jsonl --platform <p> --item-id <id> --days 90`；
   - 价格带分位：历史记录中当前价的百分位（便宜 <25% 分位 / 正常 25-75% / 偏贵 >75%）。
4. 单文件自包含 HTML（CSS/JS 内联、ECharts 走 jsDelivr + cdnjs 双 CDN 兜底、字体走自托管镜像）。
5. 交付前用 `html/SKILL.md` 的 `scripts/shot.py` 自检（桌面 + 移动视口），修复 console 错误与溢出。

## 三、数据保真规则

- 每个数字来自页面实际读取或脚本输出，禁止编造；缺失字段标注"未显示"。
- 记录不足 2 条时走势区显示"基线已建立，持续采集后出走势"，不画假折线。
- 价格全部标注读取时点；券后/会员/补贴价单独标注价格类型。
- 外部链接（商品/商家/房源/航班）必须是页面实际拿到的完整 URL，**每个价格条目链接列强制非空**（可点击，用户可直接打开核对）；无链接的条目标注"未取得链接"并说明原因，不得以搜索页代替。
- 报告开头附一行任务耗时/数据范围说明（如"本次采集 3 家平台，耗时约 6 分钟，价格截至 13:07"）。
- 医疗类报告在页脚强制附边界声明："仅提供价格信息，不构成诊疗建议"。
